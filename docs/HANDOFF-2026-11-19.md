# riff 交接：从 nyan 抽出的 web 工具（2026-11-19）

## 你在接什么

`blxzer77/riff-plugins` 这个仓库正在做一个功能：**`riff web`，多 provider 网页搜索 + 原文抓取**，从 nyan
（`blxzer77/nyan`，是 `Haleclipse/CometixCode` 的 fork）抽出来，做成一个装在 PATH 上的二进制，配一份 skill 和四家 agent

设计已由用户审定：**`docs/design.md`**（约 400 行，中文）。那份文档是权威依据，本文件只讲"现在到哪了、怎么继续"。

## 已实现

**二进制 `riff`**（`crates/riff` + `features/web`）：

- `riff web search|fetch|reset|doctor`、`riff init`、`riff hook pretooluse|sessionstart`。
- 搜索：7 家 provider 聚合（anysearch / brave / deepseek / exa / firecrawl / tavily / searxng）+ RRF + 可选精排。
- 抓取：SSRF 检查（私网、端口、内容类型白名单）、代理模式、provider 回退、内容寻址快照、`--range` 续读、PDF 经 pdftotext。
- Decision Provider：5 个 `web.*` 决策点，后端 EMRank，默认 `cloudflare/clef`。
- 状态：会话预算、provider 冷却、URL 索引、候选、探针都落盘在 `$RIFF_HOME/state/`；同会话加独占锁；健康状态只回写本进程改过的条目。

**skill**：`skills/searching-the-web/` + `evals/searching-the-web/`（替身 `riff` 离线跑 3 个用例）。

**适配层**：

| Agent | 接法 |
|---|---|
| Claude Code | `plugins/riff-web/` 纯 hook 插件（PreToolUse 拦 `WebSearch\|WebFetch`，SessionStart 传会话 id）；skill 在根级 `riff` 插件里 |
| Codex | **无插件**：`web_search = "disabled"` 关内置搜索，`CODEX_SESSION_ID` 宿主已注入，步骤在 `plugins/riff-web/codex.md` |
| Antigravity | 仓库根即插件根（`.antigravity-plugin/` + 根 `hooks.json`） |
| pi | 仓库根即包根（`package.json` 的 `pi` 字段）+ `pi/extensions/riff-web.ts` |

清单唯一手写来源是 `plugins/riff-web/source.json`；`scripts/gen-manifests.py` 生成其余，CI 用 `--check` 判过期。

## 关键决定（别推翻，除非用户改口）

1. **许可证**：nyan 是 AGPL-3.0，riff-plugins 是 Apache-2.0。只搬 `git blame` 全部为 blxzer77 的文件；
   Haleclipse 写的 `proxy.rs`/`tls_provider.rs`/`mtls.rs`/`ca_certs*.rs` **不搬**，`net.rs` 是重写的。
   以后从 nyan 再搬代码前先 blame。
2. **短进程**，不做常驻 daemon；状态落盘。
3. **缓存命中率是第一约束**（用户原话"非常非常非常重要"）：工具输出必须字节稳定，排序确定，不放耗时/请求 id/本次时间。
4. **Decision Provider 用 clef**（jev-1.14.0 已下架，jev 其余版本钱包余额不足，clef-flash 批量判断几乎全错）。
   代价：每次搜索多约 1.3 s，用户接受。
5. **内置 web 工具默认拦截**，riff 不可用时放行（无配置、无 key、预算用尽、全部冷却），`web.interceptBuiltin` 可关。
